# X2C-QZVPPD-CCSD(T) local potential curves

Local five-point potential-energy curves were calculated around the
neutral and anion minima using SFX2C-1e-ROHF-CCSD(T)/def2-QZVPPD.

The curves provide:

- high-level equilibrium bond lengths
- harmonic vibrational frequencies
- zero-point energies
- geometry-relaxation contribution to the EA
- ZPE contribution to the EA

Current buildup:

- fixed-geometry electronic EA: ~0.90466 eV
- optimized electronic EA: ~0.88805 eV
- geometry contribution: ~-0.01661 eV
- ZPE contribution: ~+0.03705 eV
- EA(v=0) before SOC: ~0.92510 eV

This is the current best pre-SOC FeH result.
