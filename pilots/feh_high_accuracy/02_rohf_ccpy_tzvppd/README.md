# FeH ROHF-CC control at def2-TZVPPD

Independent single-reference control branch based on spin-pure ROHF
references and CCpy.

Frozen core:
Fe 1s, 2s and 2p = 5 spatial orbitals.

Methods:

- ROHF
- CCSD
- CCSD(T)
- CR-CC(2,3) A-D

Representative electronic EAs:

- CCSD: ~0.8711 eV
- CCSD(T): ~0.8349 eV
- CR-CC(2,3)_D: ~0.8011 eV

The large T1 amplitudes show that FeH remains a difficult
single-reference system, so these results are used as an independent
control rather than accepted blindly as final values.
