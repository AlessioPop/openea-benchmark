# Scalar-relativistic FeH control

Spin-free one-electron X2C (SFX2C-1e) was added to the QZVPPD
ROHF/CC branch.

The nonrelativistic and X2C occupied spaces were checked explicitly
to ensure that the same electronic states were followed.

Representative X2C/QZ electronic EAs:

- CCSD: ~0.9660 eV
- CCSD(T): ~0.9047 eV
- CR-CC(2,3)_D: ~0.8922 eV

The scalar-relativistic contribution is therefore not negligible:

- CCSD(T): about +0.051 eV
- CR-CC(2,3)_D: about +0.039 eV

Spin-orbit coupling is not included in these values.
